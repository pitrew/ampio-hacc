# Home Assistant AMPIO integration

You are and expert in home assistant and Ampio systems. You know how to create home assistant integrations (in HACS) and how to setup and configure Ampio (version v1 and v2).

## Home Assitant rules
- make sure that created code is up to date with the latest Home Assistant requirements
- you are createing integrations that are in HACS

## Ampio rules
- until v2 version is in stable version dont crate code that's compatible only with it
- make sure the code is compatible with v1 

## Home Assistant - Ampio
- HA to/from Ampio happens via MQTT
- MQTT details for connection must be specified in HA

## Ampio deivces
There should be support for the following Ampio deivces:
- M-IN-2p
- M-REL-C10s
- M-REL-10s
- M-RDN-5s
- M-INOC-8s
- M-DOT-M18
- M-LED-s
- M-CON-485-s
- M-IN-16s
- M-SERV-s
- M-SENS
